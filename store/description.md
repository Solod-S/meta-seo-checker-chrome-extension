# META SEO Checker — Chrome Web Store Description

## Summary / Short Description (up to 132 chars)
Inspect titles, meta tags, headings, images, links, Open Graph, Twitter Cards and structured data in one click.

---

## Detailed Description

**META SEO Checker** is a fast, lightweight on-page SEO inspector designed for developers, webmasters, and SEO professionals.

With a single click on the extension icon, inspect essential on-page SEO elements without leaving your active tab. The extension runs 100% locally in your browser with zero tracking, zero external scripts, and no backend dependencies.

### 🌟 Key Features

#### 1. SEO Summary & Health Check
- **Title Tag:** Instant length counter, duplicate tag detection, and optimal length recommendations.
- **Meta Description:** Character counter, duplicate detection, and best practice warnings.
- **Canonical URL:** Verification of presence, self-referencing check, and relative URL warnings.
- **Robots Directives:** Real-time detection of `noindex`, `nofollow`, `noarchive`, and other meta robots directives.
- **Technical Signals:** HTML `lang`, `viewport`, `charset`, and `hreflang` validation.
- **Instant SEO Report:** Copy a formatted Markdown SEO audit report with a single click.

#### 2. Headings Inspector (H1–H6)
- Complete hierarchy visualization in DOM order with level indentation.
- Automatic detection of missing H1, multiple H1s, empty headings, and skipped levels (e.g. H1 → H3).
- Instant **Highlight on Page** to jump directly to any heading in the page layout.
- Quick text copying and level-based filtering.

#### 3. Images & ALT Text Audit
- Full inventory of all `<img>` tags on the page.
- Clear separation between missing ALT attributes and intentional decorative empty ALTs (`alt=""`).
- Image preview thumbnails with intrinsic and rendered dimensions.
- Detection of lazy loading (`loading="lazy"`) and missing image title attributes.
- Live element highlighting and direct image URL copying.

#### 4. Links & Anchor Text Analysis
- Automatic classification: Internal, External, Anchors, Mailto, Tel, and Empty links.
- Link relationship parsing: `nofollow`, `sponsored`, `ugc`, `noopener`, and `noreferrer`.
- Unique URL counting and occurrence counters for duplicate links.
- Fast multi-criteria search by anchor text, target URL, and link attributes.

#### 5. Social & Structured Data (Schema.org)
- **Open Graph:** Complete extraction of `og:title`, `og:description`, `og:image`, `og:url`, and custom properties with duplicate value detection and image previews.
- **Twitter / X Cards:** Validation of `twitter:card`, `twitter:title`, `twitter:image`, and account tags.
- **Structured Data (JSON-LD):** Safe syntax parsing with detection of Schema `@context`, `@type`, and `@graph` entities. Formatted read-only code viewer and syntax error alerts.
- **Microdata & RDFa:** Detection of `itemscope`, `itemtype`, and RDFa attributes.
- **Direct Validator Shortcut:** One-click launcher for the official Google Rich Results Test tool.
